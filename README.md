# 🎯 Python KBC Quiz Game

A simple **KBC-style Quiz Game** built using Python. The game asks multiple-choice questions and rewards the player with increasing prize money for every correct answer.

## 📌 About the Project

This project is a beginner-friendly Python quiz game inspired by the format of **Kaun Banega Crorepati (KBC)**.

Players are given multiple-choice questions with four options. The player enters the option number, and the program checks whether the answer is correct.

If the answer is correct, the player moves to the next question and wins the corresponding prize money.

If the answer is incorrect, the game ends.

## ✨ Features

- 🎯 Multiple-choice questions
- 💰 Increasing prize money
- ✅ Automatic answer validation
- ❌ Game ends on an incorrect answer
- 🏆 Displays the amount won
- 🐍 Beginner-friendly Python project

## 🛠️ Technologies Used

- Python
- Lists
- `for` loop
- `if-else` statements
- User input
- F-strings
